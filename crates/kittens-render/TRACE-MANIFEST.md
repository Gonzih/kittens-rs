# K2R-0 trace manifest

SPEC section 8 requires each suite row to map to named evidence and publish
its negative boundaries beside it. Accordingly, every row below names an
executable or compiling negative control, or says explicitly why that row has
none. The UI-pass suite and README publish compiling escape surfaces enforced
only by documentation. Exit-review finding 14 requires this manifest.
Statuses: ✓ (oracle in CI), ✓ (host integration) (host oracle in CI with
physical fidelity still gated), **CLOSED WITH SCOPE** (linked target evidence
with named runtime gaps), **documentation** (prose contract with a compiling
control), **OPEN** (host work remaining), **GATED** (blocked on a named
external gate).
