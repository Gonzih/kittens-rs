1. **Blocker — [runner.rs:120](/Users/feral/mydev/rust-kittens/crates/kittens-code-driver-tokio/src/runner.rs:120).** An append failure recursively discharges `PersistFailed` actions, whose error event itself requires another append. A persistent store failure therefore recurses indefinitely; a transient failure returns to the original batch and may publish events or start effects whose records were never durable. This violates L-A2b, L-A3, and fatal `store_io` handling. **Suggested fix:** latch driver failure, abandon the remaining batch, cancel owned effects, and report the fatal condition without attempting to commit through the failed appender.

2. **Blocker — [appender.rs:106](/Users/feral/mydev/rust-kittens/crates/kittens-code-driver-tokio/src/appender.rs:106).** Torn/checksum-failed tails are logically ignored but left physically in place before repairs or later session records are appended. A torn final line can be concatenated with a repair; a checksum-bad line becomes a mid-log fault. The next reopen then fails with `TailFaultNotLast`. **Suggested fix:** retain the valid-prefix byte boundary and recover storage there before further appends, or introduce an explicitly specified segment/framing mechanism that can supersede a bad tail.

3. **Blocker — [engine.rs:478](/Users/feral/mydev/rust-kittens/crates/kittens-code-core/src/engine.rs:478).** Real model/tool effects never commit `StreamStarted`, progress, or `StreamTerminal` records. Interrupt also emits no terminal-abort records ([engine.rs:335](/Users/feral/mydev/rust-kittens/crates/kittens-code-core/src/engine.rs:335)). Consequently S3 crash repair cannot discover actual in-flight engine work, and the persisted exactly-once lifecycle does not exist. Denied calls additionally publish a terminal without `ToolStarted`. **Suggested fix:** make lifecycle-record commits part of every effect transition, durably commit starts before dispatch, and commit exactly one normal/denied/failed/aborted terminal.

4. **Blocker — [engine.rs:392](/Users/feral/mydev/rust-kittens/crates/kittens-code-core/src/engine.rs:392).** Interrupt does not mark the epoch aborted or terminalize pending IDs in the ledger. Because interrupt deliberately does not bump the epoch, a late `EffectTerminal::Failed` from the cancelled effect passes validation and publishes an error after the turn ended; model/tool terminals are silently discarded without the mandated trace. **Suggested fix:** maintain per-effect states plus an aborted-epoch marker, mark every pending effect terminal at interrupt, and route every later/duplicate/wrong-kind completion through one traced-drop path.

5. **Blocker — [engine.rs:203](/Users/feral/mydev/rust-kittens/crates/kittens-code-core/src/engine.rs:203).** Resume-as-replay is absent. `Appender::open` returns records, but there is no engine replay constructor; `Engine::new` resets epoch and effect/request IDs, and the driver test merely inspects the returned vector. Resumed sessions therefore lose configuration/turn/ledger state and can reuse IDs. **Suggested fix:** replay accepted ops, configuration, lifecycle terminals, and events into fresh core state, then seed all monotonic counters from persisted maxima before accepting input.

6. **Blocker — [engine.rs:84](/Users/feral/mydev/rust-kittens/crates/kittens-code-core/src/engine.rs:84).** Q4 is not connected to the core engine: `EffectSpec` has no store-page or sub-model effects, `Engine` owns no `Executor`/query continuation, and pending RLM work has no `EffectId`, epoch, or cancellation path. The standalone executor cannot implement Q4 terminal/discard rules. **Suggested fix:** integrate query continuations into session/turn state and translate suspensions into correlated, cancellable page/sub-model effects.

7. **Blocker — [tools.rs:15](/Users/feral/mydev/rust-kittens/crates/kittens-code-driver-tokio/src/tools.rs:15).** `resolve` performs only lexical normalization. All subsequent reads and writes follow existing final or intermediate symlinks, allowing a workspace symlink to escape the root and read or overwrite arbitrary accessible paths, contrary to K2. **Suggested fix:** resolve component-by-component without following symlinks, verify containment using opened handles/canonical identities, and refuse symlinks for both source and destination paths.

8. **Major — [runner.rs:121](/Users/feral/mydev/rust-kittens/crates/kittens-code-driver-tokio/src/runner.rs:121).** L-A2b whole-batch dispatch is not enforced. Capacity is never reserved, and `engine.handle(Persisted)` occurs in the middle of the action loop before the original transition completes. The funnel is unbounded and ignores configured queue/effect limits ([runner.rs:44](/Users/feral/mydev/rust-kittens/crates/kittens-code-driver-tokio/src/runner.rs:44)). **Suggested fix:** stage/reserve the entire transition against bounded queues, dispatch it fully in order, and enqueue durability acknowledgements for the next reactor iteration.

9. **Major — [engine.rs:253](/Users/feral/mydev/rust-kittens/crates/kittens-code-core/src/engine.rs:253).** `MAX_ACTIONS` is only a `debug_assert`. A provider response with roughly thirteen auto-approved tool calls can exceed 64 actions and panic in debug; release builds return an unbounded transition. `max_active_effects` is not consulted. **Suggested fix:** use a checked bounded transition builder and refuse or incrementally schedule proposals before exceeding either action or active-effect limits.

10. **Major — [exec.rs:139](/Users/feral/mydev/rust-kittens/crates/kittens-code-core/src/rlm/exec.rs:139).** Q5’s full meter set is not implemented: recursion depth, parallel subcalls, per-ask wall time/tokens, suspended-query count, and retained continuation memory are absent. Runtime aggregate budgets also have no compile-time ceilings. **Suggested fix:** introduce validated/clamped budget data and explicit meters for every Q5 item, surfaced through protocol budget events.

11. **Major — [exec.rs:538](/Users/feral/mydev/rust-kittens/crates/kittens-code-core/src/rlm/exec.rs:538).** `ask-each` dispatches every chunk in one batch, ignoring `parallel_subcalls`; selected-byte charge failures are explicitly discarded at lines 553–555. An oversized query can therefore allocate and dispatch beyond both limits. Empty chunks also produce ambiguous `NeedAsk([])`. **Suggested fix:** charge before allocating/dispatching, bind a budget error on failure, and use an incremental bounded parallel window with immediate completion for an empty join.

12. **Major — [exec.rs:618](/Users/feral/mydev/rust-kittens/crates/kittens-code-core/src/rlm/exec.rs:618).** `ask` over `Whole` or `Range` sends an empty context, despite both being valid IR selectors. The comment relies on callers converting them to `Ref`, which the grammar and typed IR do not require. **Suggested fix:** materialize raw selections through the page-walk continuation before emitting the ask effect.

13. **Major — [exec.rs:644](/Users/feral/mydev/rust-kittens/crates/kittens-code-core/src/rlm/exec.rs:644).** RLM execution does not implement the declared semantics: grep/count/regex partition use literal `contains`, `grep --kind` is ignored, and `By::Turns` and `By::Bytes` both chunk by record count ([exec.rs:664](/Users/feral/mydev/rust-kittens/crates/kittens-code-core/src/rlm/exec.rs:664)). Q6’s pinned regex dialect is therefore not enforced. **Suggested fix:** implement the versioned regex engine and distinct turn/byte partition algorithms, including kind filtering and byte-stable goldens.

14. **Major — [window.rs:38](/Users/feral/mydev/rust-kittens/crates/kittens-code-core/src/window.rs:38).** P6/Q3 cap typing is bypassable: `TailItem::ToolResult` exposes a plain public `String`, and `WindowLayout::new` accepts arbitrary such values. RLM `Bound::Digest` and `DigestList` likewise use unbranded strings. The engine also appends truncation prose after applying the cap, making the surfaced value exceed the declared limit ([engine.rs:582](/Users/feral/mydev/rust-kittens/crates/kittens-code-core/src/engine.rs:582)). **Suggested fix:** require the appropriate `Capped<K>` types at every root-window insertion boundary and include metadata within, or separately from, the capped byte budget.

15. **Major — [tokens.rs:47](/Users/feral/mydev/rust-kittens/crates/kittens-code-core/src/tokens.rs:47).** Public token-accounting inputs can overflow at `bytes * 1000`, history-plus-tail, `error * 1000`, `reported_bytes * 1000`, and the running-mean multiplication/addition. Debug builds panic; release builds silently mis-meter compaction. **Suggested fix:** use checked or widened arithmetic with deterministic saturation/error semantics and test all `u64` extremes.

16. **Major — [appender.rs:152](/Users/feral/mydev/rust-kittens/crates/kittens-code-driver-tokio/src/appender.rs:152).** Strict sequence enforcement is only a debug assertion; release accepts gaps/regressions and resets `next_seq` from the bad record. Fresh open also panics when the header is absent and accepts a non-header, invalid-checksum, incompatible, or sequence-exhausted header ([appender.rs:80](/Users/feral/mydev/rust-kittens/crates/kittens-code-driver-tokio/src/appender.rs:80)). One-writer locking is absent. **Suggested fix:** return typed errors before writing, validate fresh headers identically to existing ones, use checked increments, and acquire an exclusive writer lock.

17. **Major — [ir.rs:49](/Users/feral/mydev/rust-kittens/crates/kittens-code-core/src/rlm/ir.rs:49).** `Ref::new(0)` and deserialization can construct an invalid reference; executor expressions such as `chunks_line - 1` then panic in debug ([exec.rs:538](/Users/feral/mydev/rust-kittens/crates/kittens-code-core/src/rlm/exec.rs:538)). Binding slot numbers are also trusted rather than validated. **Suggested fix:** make references nonzero validated values, deserialize through checked constructors, validate query structure at executor admission, and use checked indexing throughout.

18. **Major — [event.rs:46](/Users/feral/mydev/rust-kittens/crates/kittens-code-protocol/src/event.rs:46).** P2 unknown-event preservation is not implementable with the derived closed enum: an unknown tagged variant fails deserialization and no raw-byte variant or envelope retains it. `#[non_exhaustive]` only protects Rust matching; it does not provide wire tolerance. **Suggested fix:** add an unknown-preserving wire envelope/custom decoder carrying the original bytes and re-emit them unchanged.

19. **Major — [model.rs:20](/Users/feral/mydev/rust-kittens/crates/kittens-code-driver-tokio/src/model.rs:20).** M1/G10 is unimplemented: the crate advertises a `live` feature and Anthropic endpoint, but `model.rs` contains only the jail client, with no streaming client, retry ladder, SSE delta pump, or cancellation-aware backoff. **Suggested fix:** implement the feature-gated live client and its retry/circuit-breaker and streaming contracts before calling KC0 complete.

20. **Major — [window.rs:103](/Users/feral/mydev/rust-kittens/crates/kittens-code-core/src/window.rs:103).** Tail atomicity checks only that each result has some earlier call. It accepts calls with no terminal, duplicate terminals, and duplicate call IDs, so it does not enforce “never splits a call from its terminal.” **Suggested fix:** validate a one-to-one ordered call/terminal lifecycle and decide explicitly how genuinely in-flight calls are represented.

21. **Major — [Cargo.toml:2](/Users/feral/mydev/rust-kittens/Cargo.toml:2).** T1’s required `fixtures/code-no-std` link gate does not exist; current thumb CI builds only the original `kittens` fixtures ([ci.yml:24](/Users/feral/mydev/rust-kittens/.github/workflows/ci.yml:24)). Source/dependency inspection shows protocol/core are presently `no_std`-clean, but portability is not proven on either required target. **Suggested fix:** add the specified protocol+core thumb and wasm link fixture and CI commands.

22. **Minor — [tests/engine.rs:139](/Users/feral/mydev/rust-kittens/crates/kittens-code-core/tests/engine.rs:139).** The ledger tests cover a duplicate and a numerically different epoch, but not completion-after-interrupt in the unchanged epoch, wrong terminal kind, unknown effect ID, driver failure, tool/timer/shutdown cancellation, or abort-record persistence. **Suggested fix:** add the full G4b matrix and assert both ledger state and trace/terminal records.

23. **Minor — [tests/rlm_exec.rs:24](/Users/feral/mydev/rust-kittens/crates/kittens-code-core/tests/rlm_exec.rs:24).** Adversarial RLM coverage is sparse: no exactly-at-limit cases, zero/max budgets, oversized page/answer/chunk inputs, repeated/nonadvancing cursors, empty partitions, malformed/duplicate/out-of-range ask results, invalid `%0`, or tests for the omitted meters. **Suggested fix:** add boundary and property tests for every meter and continuation state.

24. **Minor — [tests/session.rs:132](/Users/feral/mydev/rust-kittens/crates/kittens-code-driver-tokio/tests/session.rs:132).** Appender tests do not exercise a real torn/checksum tail followed by repair/append and a second reopen, out-of-order batches, partial-write failure, persistent `sync_data` failure, invalid fresh headers, or competing writers. **Suggested fix:** add filesystem-level fault-injection tests around recovery and dispatch ordering.

25. **Minor — [tools.rs:159](/Users/feral/mydev/rust-kittens/crates/kittens-code-driver-tokio/src/tools.rs:159).** Tool tests cover only absolute and simple `../` paths. They omit final/intermediate symlinks, symlink swaps, empty paths, mixed separator/platform variants, malformed JSON, huge input/output, CRLF fuzzy edits, and write failure atomicity. **Suggested fix:** add per-driver K2/G7e adversarial fixtures using real symlinks and malformed/oversized requests.

Clean subchecks: the checksum computation itself covers `seq`, kind, transaction, epoch, and complete payload, and excludes only the checksum field as S3 requires. Existing-log schema epoch is checked before any repair append, satisfying the mutation-safety part of S6. Protocol/core contain no accidental `std` usage and no floating-point behavioral decisions; the generic checksum serializer’s float support is not currently on a behavioral path. Normal nonempty `ask-each` rejoin preserves partition order, and the basic meter comparison correctly allows usage exactly equal to its limit.

**Verdict:** The KC0 spine is not sound to build the remaining gates on. Durable-failure handling can recurse and publish/start undurable work, damaged-tail recovery produces unreopenable logs, real effects are absent from the persisted terminal ledger, resume does not replay state, RLM continuations are not integrated and omit core budgets, and filesystem tools permit symlink escape. Those blockers should be resolved—and the controlling spec frozen, as v0.8 still says implementation is unauthorized—before extending the implementation.
