## 1. TUI — why best in class
- **Rendering (Fact):** `xai-grok-pager-render/src/render/draw.rs:444-477` bypasses ratatui `try_draw`: DEC 2026 BeginSynchronizedUpdate → diff → flush → EndSynchronizedUpdate per frame. `draw.rs:467-470` **zero-byte idle frames** (no cell diff ⇒ discard writer buffer) — cursor blink survives redraw loop. `xai-ratatui-inline/src/terminal.rs:157-317` double buffer + custom `diff_large` (fixes u16 truncation >65535 cells); per-cell OSC-8 hyperlink layer diffed in lockstep (:328-407).
- **Frame pacing (Fact):** `draw.rs:172-233` whole frame in one Vec<u8>, handed to dedicated writer thread; `app/event_loop.rs:320-418` Presenter with dirty-coalescing + in-flight frame acknowledgement (never issue frame N+1 until N written) + `min_draw_interval` probed from display refresh Hz at startup (`display_refresh_startup.rs:20-112`). PTY back-pressure stalls only the writer thread.
- **Widget/layout (Fact):** `scrollback/entry.rs:74-325` per-entry 4-tier RefCell caches, 3 invalidation grades (content / width / memory-pressure-evict-keeping-heights). `scrollback/state/layout.rs:699-731` estimate→exact height upgrade only within visible window + margin; `virtual_y` prefix sums + `partition_point`; width-stable `ScrollAnchor{entry_idx, logical_line, sub_rows}` (:18-23). 10k-entry transcripts open instantly.
- **Streaming markdown (Fact):** `xai-grok-markdown/src/streaming.rs:1-51,310-432` checkpoint-freeze renderer — freezes output at depth-0 block boundaries, re-parses only the tail (O(N²)→O(N)). syntect + two_face (`syntax.rs:19-42`); `open_code_highlighter.rs:1-120` persists syntect ParseState across tail re-renders for open fences + 256KiB memo for closed fences in tail (fixed recorded 4.5s freeze).
- **Handoff (Fact):** `event_loop.rs:251-318` single `suspend_for_child` path: park input reader (bounded 500ms) → drain writer (750ms) → leave alt screen → raw mode off → child → restore + drain stale DA/DSR replies; timeout ⇒ child NOT started, retried at 250ms. `wrap_restore.rs:46-418` tracks modes a PTY child enabled, restores in canonical order. `xai-tty-utils` detaches children from controlling TTY. Crash handler restores terminal on panic/SIGTERM (`app/mod.rs:1335`).
- **Modes (Fact):** fullscreen (alt screen), inline (`Viewport::Inline` + `insert_before` into native scrollback, DECSTBM variant), minimal ("committed frontier" of finalized entries pushed to native scrollback, `xai-grok-pager-minimal/src/commit.rs:1-42`). Resize debounced 16ms; wheel-vs-trackpad stream classification (`input/mouse.rs:1-214`).

## 2. Agent loop
- **Fact:** loop in `xai-grok-shell/src/session/acp_session_impl/turn.rs:1895,2004` (`process_conversation_turn`, sample→tools→resample); `turn.rs:2754` anti-doom-loop via identical-tool-call run detection (16 generic / 4 no-ops) instead of fixed iteration cap.
- **System prompt (Fact):** `xai-grok-agent/templates/prompt.md` (45 lines, XOR-encrypted at build, `Zeroizing<String>`); custom `${{ }}` template engine — prompt sections self-omit when a tool is disabled; 16KiB soft ceiling regression-tested. AGENTS.md/CLAUDE.md/.cursor rules merged NOT into system prompt but as escaped system-reminder in the user message (`prompt/agents_md.rs:150,311,329` — leading `<` HTML-escaped as prompt-injection boundary).
- **Model I/O (Observation):** async-openai fork for types only; transport = raw reqwest + hand-parsed SSE (`xai-grok-sampler/src/client.rs:690,102`). Three wire dialects (Responses / ChatCompletions / Anthropic-style).
- **Tools (Fact):** schemars-derived schemas (`xai-grok-tools/src/registry/types.rs:1837`); `xai-tool-runtime` two-trait design (RPITIT `Tool` + object-safe `ToolDyn`); every tool returns a stream ending in exactly one Terminal item. **Parallel dispatch:** approval serial, execution concurrent via FuturesUnordered rejoined by index (`tool_calls.rs:403,611`); plan-exit tools forced into second batch (ordering barrier).
- **Subagents (Fact):** `task` tool, depth-capped, allow-listed, disabled-by-config rejected pre-spawn; children **share parent's hunk tracker/fs/terminal/env**; forked context summarized not copied (`xai-grok-subagent-resolution/src/context.rs:48`); large results return by file reference/GCS upload, not inline.
- **Hooks (Fact):** macro-generated event table (`xai-grok-hooks/src/event.rs:25`); PreToolUse can Deny, Stop can force continuation, else observe-only; hooks **fail open** on timeout/crash. Sandbox denies hook-file writes and `sandbox.toml` edits (agent can't edit its own cage).
- **Retry (Fact):** no circuit breaker on model path — `RetryPolicy` ladder (`xai-grok-sampler/src/retry.rs`): exp backoff ±20% jitter, ~5.5min budget, 429 Retry-After honored unclamped but count-capped, 525/526 never retried; content-aware `RetryWithImageStrip`, `RetryWithClientRebuild`; semantic retries `CompactAndResubmit` / `RefreshAuthAndResubmit` (`sampler_turn.rs:816`). CancellationToken end-to-end; retry sleeps cancel-aware.

## 3. Context management
- **Compaction (Fact):** trigger 85% of window (`xai-grok-compaction/.../config.rs:13`); **prefire** background summarization starts ~75% so summary is ready before the hard line (`session/compaction.rs:38`), cache-keyed by conversation fingerprint. Post-compaction history = [system, user_info, AGENTS.md reminder, last_user_query, verbatim tail since last real user turn, model summary, system_reminder] (`assemble.rs:50-101`); pre-summary strip drops tool results/reasoning/images. Tail split never orphans tool results from their call (API-400 guard). Three trigger paths: between-turn (85%), mid-turn hard-overflow with auto-continue, 400-context-length error recovery; sticky suppression after deterministic failure. Mechanical drop-oldest-turns fallback. Two-pass mode: summarize oldest 95% → NOTE₁, rewrite NOTE₁+tail → NOTE₂.
- **Tokens (Fact):** no tokenizer — bytes/4 heuristic + 765/image (`xai-token-estimation/src/lib.rs:9-19`); driving number hybrid: exact provider usage for history + bytes/4 for in-flight tail (`xai-chat-state/src/actor/mod.rs:330-333`).
- **Reminders (Fact):** all system-reminder-wrapped, hidden by TUI. Post-compaction rebuild: agent-edited files, AGENTS.md, skills, background-tasks/TODO/subagents, MCP servers, recovered memory (`helpers/compaction_context.rs:117-237`). In-flight: TodoGate, date rollover, post-abort one-shot, LazinessDetector nudges. Mid-turn user interjections = synthetic user message with **no deferral instruction** (`xai-interjection-core/src/format.rs:22-32`); background notifications drain only when idle, batched.
- **Memory (Fact):** experimental (GROK_MEMORY=1); markdown at ~/.grok/memory/ (global + blake3(cwd) workspace dirs + daily session logs); sqlite-vec embeddings, hybrid search + MMR. Injected once into leading system message on first turn — guarded against re-injection to preserve KV-cache prefix (`turn.rs:1690`); top-3 re-search appended after compaction. "autoDream" background LLM consolidation rewrites MEMORY.md from session logs, lock-protected.

## 4. Sessions / resume / replay
- **Fact:** JSONL, not SQLite: per-session `updates.jsonl` (durable source of truth = raw ACP session/update + _x.ai/session/update envelopes with timestamps) + `chat_history.jsonl` (rebuildable reducer cache) under `sessions/<encoded-cwd>/<id>/` (`session/storage/mod.rs:37-600`). Atomic temp+rename, macOS F_FULLFSYNC. `xai-sqlite-journal` = misleading name (WAL-vs-rollback PRAGMA helper); SQLite only as derived FTS5 search index.
- **Resume = replay (Fact):** `mvp_agent/mod.rs:1437-1560` re-emits stored log lines as live ACP notifications tagged `_meta.isReplay`; offset-based delta replay for reconnect; unknown cursor → full replay; event-ID counter re-seeded from log max. Rewind = sentinel marker elided at replay, not truncation. Fork copies session dir with parent tracking + fresh UUID. Deterministic replay testkit synthesizes exact updates.jsonl with expected-line-count oracle; e2e resume tested through real ACP over in-memory duplex.

## 5. ACP decoupling
- **Fact:** Zed's `agent-client-protocol` 0.10.4, unstable features. `MvpAgent` implements agent side (`acp_agent.rs:28`); TUI is an ordinary ACP **client** (`xai-grok-pager/src/acp/leader_bridge.rs:242-256`) — no privileged TUI-only path; Zed/IDEs consume identical stream. Boundary: `xai-acp-lib` gateway channel — `impl acp::Agent for AcpGatewaySender`: a plain mpsc sender satisfies the Agent trait; transport swaps freely between stdio JSON-RPC, in-process `tokio::io::simplex`, Unix-socket leader IPC with zero agent changes. xAI extensions ride parallel `_x.ai/session/update`; clients ignoring it degrade gracefully. Conversation state = lock-free actor (`xai-chat-state`).
