Rust · no_std · flagship: kittens-code

Make async orchestration harder to get wrong.

Kittens turns selected ordering facts in long-lived Rust systems into compiler inputs—so shutdown order, starvation hazards, bounded work, and source lifecycles are visible before an edit ships. Its flagship demo carries that discipline into a complete coding-agent harness.

It is a small orchestration kernel, not a runtime, scheduler, HAL, or sandbox. Handlers stay ordinary Rust. The boundaries stay visible.

Transcript law

One checksummed append-only JSONL log is recovery source, audit trail, and RLM ground truth. Resume replays it; torn tails truncate to the last valid frame; incomplete streams receive persisted crash terminals.

Driver protocol + adversarial second-reopen tests
⌕

Context law

The live window compacts, but records do not disappear. A budgeted continuation can grep, slice, partition, ask sub-models, and return a capped answer through the ordinary recall tool path.

Core state machine + typed RLM IR
≤

Budget law

Model-visible values pass through branded caps; query and aggregate meters stop work at compiled ceilings. Every behavioral counter uses checked or saturating integer math for byte-identical replay.

Type system + private admission + property tests
◇

Effect law

IO cannot sneak into core. Model, store-page, VFS, timer, and sub-model work is correlated by effect id and turn epoch; only an owned, current effect can close a lifecycle.

Sans-IO API + exactly-once terminal ledger
▣

Model law

The default jail is scripted, offline, and deterministic. The optional live feature adds Anthropic-dialect SSE, bounded retry with jitter and Retry-After, cancellation, and a circuit breaker.

Default-lean feature boundary + deterministic scenarios
μ

Portability law

Protocol and core link on thumbv7em-none-eabi and wasm32-unknown-unknown. That proves the center is portable—not that an Embassy/WASI/Web driver or on-silicon agent already exists.

Cross-target link gates + dependency-tree discipline

Run it without a network

The default model is a deterministic jail.

Install the headless composition root, script one model response, then send newline-delimited Ops. You will get turn and model Events on stdout plus a checksummed session log you can reopen.

cargo install kittens-code-cli --version 0.0.1

  • Default backend: jail; no HTTP/TLS dependency or network call.
  • Optional live mode: rebuild with --features live and provide bootstrap-only credentials.
  • CLI args override environment, which overrides documented defaults.

Recall, not amnesia

The model can query the transcript it no longer keeps in-window.

The recall tool lowers one tiny, typed, versioned verb language into a suspendable continuation. Store pages and sub-model asks leave as effects; caps and meters remain core law. Compaction removes window copies, never log truth.

grep "store_io|cancelled" --ctx=2

Value caps truncate. Aggregate meters stop the query. Full records stay in the log.

The vision

Bring the whole ball of yarn into view.

Async systems fail in different ways. Kittens does not flatten them into one magic percentage. It attacks each class at the strongest honest layer.

  1. 01

    Structure

    Inexpressible

    Safe Rust ownership plus a single-owner reactor make memory races and many intra-reactor shared-state races unwritable on the supported path.

    Ordinary Rust
  2. 02

    Declarations

    Static detection

    The reactor! compiler checks declared priority, shutdown, starvation, drain, phase, and source-admission relationships.

    Macro + sealed traits
  3. 03

    Scenarios

    Deterministic schedules

    Dynamic protocols—stale acknowledgements, cancellation races, rearming, and failure recovery—belong in private state machines and adversarial tests.

    Runtime tests
↳

Confidence ends where the declared vocabulary ends.

Raw spawns and selection, side channels, handler loops, and cross-task webs are escape surface. Kittens measures and publishes that boundary; it does not hide it.

Familiar Rust, stricter edits

The topology sits beside the work.

Sources remain persistent. Priority stays lexical. Relationships are attributes an agent can discover, preserve, and repair from local compiler feedback.

  • 01 Shutdown is visibly first.
  • 02 Readiness and bounded drain are declared.
  • 03 An explicit waiver carries its reason.

The honest edge: a handler can still block, await an unreviewed operation, or write an unchecked loop. The macro checks its declared boundary, not arbitrary Rust inside it.

reactor.rs · excerpt 
kittens::reactor! {
    policy {
        selection: biased;
        required_phases: [after_event];
    }

    /// Shutdown leads so a ready stream cannot hide teardown.
    #[source(stop)]
    #[readiness(quiescent)]
    #[shutdown]
    _ = sources.stop => { Ok(0) }

    #[source(events)]
    #[readiness(may_remain_ready)]
    #[starvation(allowed, reason = "no lower interactive source")]
    #[drain(max = 4)]
    #[last]
    event = sources.events => {
        Ok(Control::Continue)
    }

    after_event {
        // Once after a successful service window.
        Ok(())
    }
}

Direction, clearly labeled

From one harness to harnesses that build harnesses.

The ambition is one context-reconstructible orchestration vocabulary across domains—not a bigger runtime and not a pile of invisible conventions.

  1. Now

    One harness, visible end to end

    kittens-code makes the agent loop inspectable from JSONL wire to sans-IO transition, durable effect, budgeted recall, and client Event.

  2. Profiles

    Component and engine authors

    TUI and rendering protocols move repeated domain races behind ownership, admission, and deterministic state machines without redefining the kernel.

  3. Direction

    Meta-harnesses

    Harnesses that generate and supervise other harnesses need one spelling per operation and machine-readable topology they can emit and verify.

Gated direction, not shipped API: deterministic schedule exploration, machine-readable topology, broader runtime profiles, and escape-surface measurement graduate only with their named evidence.
